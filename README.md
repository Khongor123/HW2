# Assignment 2 Part 2

1. TimeCode.h - declaration of the TimeCode class
2. TimeCode.cpp3 - implementation of the TimeCode class
3. TimeCodeTests.cpp - tests for the TimeCode class from Part 1
4. NasaLaunchAnalysis.cpp - reads data from Space_Corrected.csv and calculates the average launch time
5. PaintDryTimer.cpp - tracks drying times for batches of painted spheres
6. Space_Corrected.csv - data used by NasaLaunchAnalysis.cpp
7. Makefile - compiles all programs

Run: `make` to compile

- ./nasa for NasaLaunchAnalysis.cpp
- ./pdt for PaintDryTimer.cpp
- ./tct for TimeCodeTests.cpp
